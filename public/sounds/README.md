# Booth sound effects

Drop your own audio files here and LumiStrip will automatically use them
instead of the built-in synthesized fallback tones:

- `countdown-tick.mp3` — plays once per second during the 5-4-3-2-1 countdown
- `shutter.mp3` — plays the instant each photo is captured
- `print-chime.mp3` — plays once when all 4 photos are done

No code changes needed — just add the files with these exact names.
